# Brain Atlas 2120

Interactive neuroanatomy study website for psychology and medical students.

## Features

- Futuristic 3D brain atlas with clickable structures
- Compact study console with expandable learning cards
- Neuron basics page with visual learning support
- Student study board for structure, function, lesion, and pathway review

## Run Locally

Open `index.html` directly or serve the folder with any static server.
